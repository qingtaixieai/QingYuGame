# 二级地块

三级复用局部地块模块。表按 frontend/src/sceneModules.ts 登记，实际通行看场景格。

| 代码 | 名称 | 说明 |
| --- | --- | --- |
| `grass` | 草地 | 野外通行地面。 |
| `forest` | 林地 | 用于林带与林缘过渡。 |
| `dirt` | 土路 | 连接野外区域的地面。 |
| `paving` | 石板路 | 用于街道和建筑门前。 |
| `street` | 街道 | 连续的城镇通路。 |
| `plaza` | 广场 | 供旅人通行的开阔空间。 |
| `sand` | 沙地 | 位于陆地和水面之间。 |
| `rock` | 岩地 | 岩层地面，部分岩块会阻挡移动。 |
| `bridge` | 桥面 | 跨越水面的通行地面。 |
| `shallow` | 浅水 | 浅水区域，通行以格子详情为准。 |
| `deep` | 深水 | 深水区域，无法步行通过。 |
| `building` | 建筑占地 | 建筑覆盖的不可通行区域。 |
| `wall` | 墙体 | 整个墙格无法通行。 |
| `floor` | 木地板 | 室内通行地面。 |
| `lobby` | 门厅 | 入口附近的室内通行区域。 |
| `lounge` | 休息区 | 供旅人停留的室内区域。 |
| `reception` | 柜台区 | 门厅通往柜台的室内区域。 |
| `rug` | 地毯 | 可通行的室内铺面。 |
| `bed` | 床铺 | 占据完整格子的室内陈设。 |
| `shelf` | 货架 | 占据完整格子的陈列家具。 |
| `furniture` | 家具 | 占据格子的室内陈设。 |
| `inn-counter` | 旅店柜台 | 沿墙放置的室内陈设，墙格不可通行。 |
