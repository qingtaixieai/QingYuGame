# 交互组件

按 frontend/src/sceneModules.ts 的组件定义登记。

| 代码 | 名称 | 功能 |
| --- | --- | --- |
| `door` | 门 | 在室内与室外之间通行。 |
| `leave` | 地块出口 | 返回大世界或跨入相邻地块。 |
| `ferry` | 公共渡船 | 在大陆和远屿间往返。未建成时可投入材料。 |
| `gather` | 采集点 | 采集木头、石头等资源。 |
| `craft` | 制作设施 | 使用配方制作物品。 |
| `shop` | 商店柜台 | 用铜币购买和出售物品。 |
| `rest` | 旅店休整 | 休整以恢复生命。 |
| `loot` | 遗留物 | 查看并拾取地上的掉落物。 |
