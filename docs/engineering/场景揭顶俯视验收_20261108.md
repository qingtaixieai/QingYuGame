# 二三级地图揭顶俯视：本地实现与验收

## 范围

用户选择第一种揭顶俯视方向，要求沿用线上版本的玩法与已有后端。当前交付是本地第一版视觉实现，未推送、未部署，最终美术认可仍由用户实际查看决定。

- SceneArtwork提供地面纹理、低墙、家具、树木/树桩、石头/矿石、植物、工作台/铁砧/熔炉。
- SceneView接入真实数据；移动时显示网格，选格高亮；关闭的门有门扇和文字状态。设施格不再重复绘制通用桌子。
- 室内进入时镜头对准场景中心，修正门口居中导致上半房间被裁掉。相机调整不改变局部坐标或寻路。
- BattleView按同一坐标复用地面、墙及家具展示；红格、移动、伤害、回合与后端判定未修改。
- 横屏详情限高滚动，底部工具条保留横向滚动；装饰层不接收指针事件。

## 前后端契约

本轮无数据库迁移、无业务接口修改。cells、ScenePosition、SceneObject、门、公告栏位置均为当前场景局部六边坐标；owner是一级地图归属，不能加到局部坐标上。后端SceneMap、SceneRuntime、SceneContentService、LawService是来源。

前端只展示terrain/walkable、depleted/inUse、door.open。普通furniture目前没有床/柜台类别，先用通用图形；工坊真实设施以对象code绘制。不能从概念图虚构互动床铺、房间或碰撞。
