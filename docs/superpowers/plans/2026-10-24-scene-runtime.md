用户已确认继续。沿用当前分支，保留第一阶段提交，不重生成既有世界/场景。

## 范围
室外二级按需保存、实际进入/离开、逐格移动、记住位置、相邻跨边、共享场景战斗；旧战斗保持兼容。室内建筑与采集制造后续实施。

## 实施与验收
- [x] V21位置/来路/战斗场景引用；SceneRuntime统一玩家和NPC的位置、合法落点、生成及恢复。首次半径15，一级/二级地面分开；不伪造完整城镇建筑。
- [x] WorldService/Controller场景查询、进出、移动与停止；切换清旧路径；断线停止但保存位置；禁止一级接口跨层绕行。
- [x] BattleService复用实际场景和位置，一级发起只拉双方及实际场景居民，旁观者自主加入；地形与范围共同校验；结束保留位置、边缘撤离进入相邻场景；旧战斗不迁位。
- [x] SceneView与BattleView共享地面显示，按需载入地图，移动二次确认、详情、跨边、回一级；移动默认关、重连关闭；保持桌面/横屏适配。
- [x] 独立数据库测试保存重入/重启、封边与占位、入战保位/全场参与/旁观不拉、战后保位、旧战场兼容；前端构建、真实浏览器桌面/横屏。
- [x] 代理只读独立验收，修复复测后复验；同步接口与交接记录。验收前不进入下一阶段。

## 实施决定
- 用持久位置表保存当前场景和每场景记忆；一级来路独立记录，不以客户端坐标作为权威。
- 场景查询读取保存地图，不每tick传721格；快照只传当前位置/场景ID与居民，切图单独读取地图。
- 延续单实例WorldService监视器及事务，不引入新的分布式运行承诺。
