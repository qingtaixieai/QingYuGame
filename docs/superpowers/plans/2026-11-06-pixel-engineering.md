# 青屿像素界面与功能工程化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 按职责分配文件，公共入口由主代理集成。

**Goal:** 交付三版可交互像素风界面供用户选型，同时补齐按功能协作的工程边界和关键数据契约。

**Architecture:** 沿用 React/TypeScript/PixiJS 与 Spring Boot 单体模块化。独立多页面预览不连接真实账户或游戏写接口；正式游戏视觉待用户选定后应用。只整理已有功能，不新增玩法。

**Tech Stack:** React 19、TypeScript 5.9、Vite 7、Java/Spring Boot、Python 工程检查。

**Spec:** 用户2026-11-06确认本对话方案并回复“开始”。三版：清新青绿、木石冒险、深色战术；统一展示大世界聊天、人物装备背包、战斗底栏，覆盖桌面与手机横屏。

## Global Constraints

- NPC与玩家共享执行与校验链，不改玩法、锁、事务或广播语义。
- 预览数据明确标示为演示，不发真实游戏动作请求。
- 每阶段独立代理验收，无阻塞后进入下一阶段。
- 不同代理不同时编辑同一文件；公共配置由主代理集成。
- 当前功能分支上工作，保留预存 `.serena/`，不改生产数据库。

## Review Focus

- 844×390横屏中聊天正文、装备说明、战斗按钮可见可操作。
- 预览入口不加载正式游戏连接，不产生WebSocket或写请求。
- 三种主题与三个场景都可切换，键盘能操作，选择状态明确。
- 模块归属覆盖全部源文件且唯一，依赖约束不误报合法共用类型。
- 数据契约测试覆盖实际Java序列化与前端字段，不只是手写样例自证。
