## 2026-11-10 整房构图方案

外部 Claude Sonnet 4.6 按 The Agency UI Designer 岗位看过原始参考图并交付分区建议，原始结果留在本机 `.local/agency-inn-composition.json`。结合 TownService 的实际生成规则后，采用以下方案。

- **构图**。主镜头看完整房间，入口朝画面下方。北侧是一条连贯的柜台背景，组合木柜、匾额、柱和灯笼。左下床、屏风与织物组成一组，右上茶桌与窗景组成一组，右下酒坛和柜架作为收边。中心是从门口延伸的石板动线，在掌柜两侧分流。用成组陈设和地面材质边界把空间串起来。
- **真实坐标**。旅店半径 4，外圈除门格 (0,4) 外都是墙格。掌柜初始格为 (0,0)，相邻地面可通行。放弃外部建议的中央 L 形实体柜台，北侧柜台组合落在不可走格，中央只保留真实掌柜及贴地装饰。休整仍按场景服务判断，不引入靠近柜台限制。
- **墙与家具**。后墙画可见立面、梁、窗和柱，前墙画低矮剖面，门洞对齐真实门。墙角和家具脚点按实际地格摆放，正面遮挡关系按脚点排序。陈设应占据已有阻挡位置，贴地毯可在可走区。室内保持青绿织物、暖木和石灰色的统一色板。
- **可交互显示**。默认保持画面干净，移动时提示实际可走格，悬停和确认高亮贴合鼠标命中的六边形。没有假功能按钮。拖拽、缩放与侧栏开合后仍按实际 SVG 坐标判定。
- **制作清单**。先做室内后墙与前缘、柜台一组、屏风床铺一组、茶桌一组、酒坛柜架一组，再看石板尺寸、接地阴影与灯光。复用现有合适素材，按整房构图决定需替换的资产。
- **验收**。以实际旅店的 1280×800 和 844×390 截图对照参考图。入口、柜台、休息区和动线应一眼可辨，侧栏、门与操作条可用。逐项实测缩放后选格、空白取消、预览与确认、进出门和旅店服务。视觉和操作分别记录，由外部代理独立复核后交用户看。
