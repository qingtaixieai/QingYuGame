# 二三级地图揭顶俯视改造

用户已确认开始；保持线上玩法基准，改进尚未部署的本地二三级地图。采用明亮像素、揭顶俯视、低墙、弱网格。生成图仅作美术方向，不作为新增玩法或布局数据。

## 前端需求
- SceneView保持所有现有移动、采集、设施、门、服务、战斗入口。
- 地板、水面、土路、石地使用确定性纹理；墙与家具严格基于真实占位，不把装饰变成障碍。
- 资源/设施用不同物件绘制，枯竭树木为树桩；门明确显示开关状态。
- 普通观察弱网格；移动、选中时突出网格与路径；不改变寻路与两次点击确认规则。
- 名称与血条错开；鼠标落格仍由统一坐标换算决定，装饰不拦截点击。
- 手机横屏详情有最大高度和滚动，底部栏有横向滚动，不遮住主要操作。

## 后端需求与接口对照
- GET /scene map.cells(terrain,walkable,q,r)、level、radius是地面与阻挡唯一来源。
- state.sceneObjects提供真实资源、设施及depleted/inUse；sceneDoors提供门格、名称、开启状态。
- /scene/move、/scene/door、/scene/cross、/production/start等请求与服务端校验保持不变，NPC/玩家共用规则不变。
- 本轮不需要数据库迁移。现有furniture缺少细分美术类型，先用通用家具表达；不可擅自标成可睡床/商店柜台。以后需要精确床、柜、灯的位置再补可选视觉字段，未确认不实现。

## 实施与验收
1. 增加纯展示SceneArtwork模块，接入SceneView，调整scene.css；检查不拦截格子输入。
2. 核对战斗时场景表现与原有判定；完成构建、工程检查、实际二级/三级桌面与横屏操作验证。
3. 外部DeepSeek只读独立审查并修复，未通过不得宣称验收完成。
4. 清理无依赖旧选型入口：先备份到忽略目录，再删除明确废弃文件与构建引用；不动正式数据、数据库、用户其他进程和预存.serena。
