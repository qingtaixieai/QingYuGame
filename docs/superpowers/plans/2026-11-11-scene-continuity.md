# 青屿场景连续性实施计划

> 使用子代理实施独立模块，合并后按真实试玩路线验证。

1. 白石城与旅店绘制。按现有门、地形和通行数据绘制商街和室内空间。验证旧存档门位置和可走格。
2. 统一地点操作区。大陆补只读路线，局部场景使用现有路线接口。用同一操作区呈现选中、移动、到达与服务状态。
3. 局部镜头与战斗。进出场景按实际落点取景。开战保留 SceneCanvas、地形、地标与镜头，切换输入和绘制叠层。保持独立旧战场可进入。
4. 验证。前端构建、工程检查、后端路线回归。用桌面和横屏走过大陆、城镇、旅店、休整与返回。浏览器检查开战前后 canvas 是同一 DOM 节点、镜头不跳和战斗输入可用。

## 验收结果

- 隔离 PostgreSQL 后端 159 项通过，前端构建和 12 项几何与道具检查通过。工程检查确认 86 条 HTTP 路由。
- 桌面 1280×800、横屏 844×390 实测大陆预览路线、走到城镇门口、进旅店、休整或取消、原门返回。港口实测展开与收起造船明细，共用一个地点操作区。
- 旅店开战、移动和结束战斗时浏览器检查同一个 canvas 节点。二级城镇开战也检查同一个 canvas 节点。
- 用户预览为 15178，使用原本地预览库。浏览器写入只在另建的 QA 库进行。
