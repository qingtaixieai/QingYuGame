- 后端岗位建议审查探索回执及 NPC 调度。保留玩家和 NPC 共用行动、合法性校验与结算。先验证回执负载冲突，定时器与巡逻卡住的推断需通过测量或复现。

## 修改阶段与负责人

1. **地图与动作入口。** 前端地图岗位负责选格模块和撤离绘制，战斗岗位负责提供武器或技能的候选格，主代理接入普通攻击、速射和火球术并维护归属清单。沿用 [探索选格与 75% 撤离方案](2026-11-15-exploration-attack-highlight.md)。桌面 1280×800 和横屏 844×390 验证范围、悬停、触控、取消及非法点击，给独立代理验收。
2. **前后端契约与状态一致性。** 平台后端负责场景动作回执和序列化，客户端集成岗位负责共享类型、快照消费和结束过渡。接口岗位同步协议、迁移说明和测试。隔离库验证重放和状态分支，浏览器验证连续战斗、跨场景、容器、断线重连。通过后由独立代理验收。
3. **运行成本、构建与交接。** 平台与后端岗位按测量结果整理重复读取或运输层瓶颈。运行基线与变更后回归，验证旁观者无法收到他人的背包等私有信息。CI 与文档岗位补工程检查、接口示例、发布核对和接手索引。主代理记录范围、性能样本环境和待复现项，由独立代理验收。

每阶段通过独立验收后再进入下一阶段。聊天、交易、制造、NPC、图鉴和世界移动作为受影响链路做回归。只有证据明确的缺陷才改玩法代码，保留当前部署和数据库边界。正式服及 GitHub 同步按后续授权执行。

## 实现与验收

### 地图和选格

`sceneSelection.ts` 提供去重后的候选格与命中判断，`SceneCanvas` 给鼠标、触控和键盘共用提交入口，`SceneView` 只负责候选格来源与动作请求。浏览器在 1280×800 验证空手攻击亮出 6 格并悬停响应，在 844×390 验证装备短弓后按速射并触控落点。两档都验证非法点击无请求、火球六格范围和取消清理。撤离标识实测完成帧填充为 75%，外圈与门口的浮现和下沉正常。阶段一独立复核通过。

### 接口与状态

V36 追加可空的回执负载字段，新请求绑定动作和落点。回执插入、合法性检查及结算在同一事务。冲突重放返回 400，失败请求允许重试，V34 历史回执只返回当前状态。实测验证失败未增加战斗版本，旧回执返回当前准备与战斗状态，已执行动作重发不会重复伤害。本地预览数据库实际完成 V35 到 V36 升级，升级后用 HTTP 验证重试、重放与冲突响应。

共享协议补齐场景遗留物、个人携带和生产等字段。浏览器入口统一校验消息外层，将旧连接、旧战斗报告的回调限制在各自生命周期。Java 集成通过真实 WebSocket 检查营地货箱及背包归属。Node 回归覆盖畸形消息、旧定时器和重用同编号时的过期回调。桌面和横屏浏览器验证了断线重连，并且重连后可以继续操作。连续战斗的报告竞态由可控计时器测试验证。阶段二独立复核通过。

### 运行成本与交接

广播共用每一轮的公共快照，各连接继续独立计算可见内容。怪物接敌按世界格定位候选者，行动前再读取目标当前状态，沿用原有战斗和 NPC 校验。工程检查遇到无法可靠解析的 `@RequestMapping` 会报错，本地 `devcheck local` 与 CI 都运行当前的纯逻辑测试。

性能样本来自本机同一隔离数据库，6 个认证 WebSocket 并行接收快照，70 次 `POST /api/stop` 触发广播。优化前后中位数为 62.2→32.1 毫秒，P95 为 77.8→38.0 毫秒，单条快照约 34.8 KB。窗口内 PostgreSQL 的 `characters` 关系扫描为 5040→1130，数据含后台调度，不能当作精确 SQL 调用量。六个连接在采样期间持续收到各自不同的背包数量，并逐次核对身份。

本地预览前端 `127.0.0.1:15195`、后端 `127.0.0.1:15194`。正式服、GitHub、手机真机及生产容量未在本轮验证。
