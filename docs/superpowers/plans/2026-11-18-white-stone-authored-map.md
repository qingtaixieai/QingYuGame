# 白石城手工样板地图开发方案

**状态**　用户已确认开工。白石城隔离样板的路网和 Pixi 素材接入已实现，运行验收见文末。

**发布补记**　2026-11-18 正式服 V36 启用了样板。发布前查明正式服白石城二级地图尚未生成，无需覆盖旧场景。候选 JAR 已在生产克隆库验证首次进城生成；正式服首次进城按同一规则生成。见[发布记录](2026-11-18-exploration-move-and-release.md)。

## 目标和范围

在青屿当前 PixiJS 工程中制作可运行的白石城样板。构图对应用户选中的正俯视效果图。主路自画面下方进入，通向中央石板广场和水井，旅店位于广场右侧，其余店铺沿街布置。固定入城镜头用于比较房屋大小、广场比例、布局密度、角色尺度和右上地点卡。画面须支持正常拖动、缩放、点击移动和战斗叠层。

首版只改白石城的二级室外地图及其外侧门口布局。沿用现有房间、服务、规则和 API。样板用本地隔离新档运行，其余城镇沿用现有生成逻辑。改造既有白石城存档另立计划，待样板获认可后按持久化状态制定迁移。

## 代理意见和取舍

- Opus 5.5 美术与前端岗位对照概念图、实拍及 `districtArt.ts`，建议拆分建筑、地面和环境装饰素材，按 Pixi 绘制层分离静态景物、角色和操作反馈。采用分层和复用思路。美术验收看入城同镜头的具体差异，不以建筑可见率或未经采样的固定帧率代替。
- Opus 5.5 后端岗位核对 `TownService.ensure` 与 `SceneRuntime`，建议只给白石城接入手工布局，复用室内 ID、服务角色和传送门创建链。采用隔离新档先跑通的方式。旧档处理不采纳删除建筑、NPC 或门再生成的建议。将来应保留已有场景、房间及服务记录，单独审查活跃战斗、角色位置、门端点、设施与地上物品。
- 主代理采用一份版本化布局描述记录稳定地点标识、门前格、占地、可通过边以及纯视觉锚点。服务端负责地块、占地与通行；前端依据现有场景坐标绘制。发现显示与通行冲突时修正布局或锚点，保留玩家与 NPC 共用的校验链。

## 阶段、分工与验收

| 阶段 | 分工与范围 | 验收 |
| --- | --- | --- |
| 1. 场景与路网 | 后端地图岗编排白石城二级地块，接入现有 `SceneRuntime`、`TownService`。主代理核对地图模板、四种服务建筑与前后端坐标。 | 本地隔离新档。可从大世界各允许的方向进出。在客户端实际沿街到旅店门前并进出，门口、地图边和各店路网连通。验证整格墙及封边，玩家和 NPC 走同一条规则。重复进入不新增房间或角色。 |
| 2. 素材与构图 | Opus 美术与前端岗按参考细化素材布局，前端美术岗在现有 Pixi 绘制链中接入可复用素材；外观配置与坐标、交互规则分开。 | 建筑包含红瓦、青瓦、旅店地标，环境包含石板、草地、树冠、水井、花箱、栅栏和灯。统一正俯视、像素密度与用光。固定镜头并排核对参考，检查门口、地标、角色及高亮依然清晰。禁止用整张参考图代替可交互地图。 |
| 3. 运行整合 | 主代理整合，独立验收岗验证 `1280×800` 和 `844×390` 实际页面。 | 连接隔离后端跑进城、沿路移动、进入和退出旅店、回大世界、同图战斗。验证桌面悬停和横屏触控模拟，测拖动、缩放、首屏及长帧，在同机同场景对照；区分真机未验证项。 |

每阶段独立验收通过后进入下一阶段。运行前端构建与相关场景回归，涉及模块归属或 HTTP 契约时跑工程检查。样板供本地体验和验收，正式服与 GitHub 同步另按授权执行。

## 实施记录

- 使用 `QINGYU_WHITE_STONE_SAMPLE=true` 在隔离后端启动样板。开关默认关闭，仅作用于首次生成的白石城二级地图。白石城场景、现有角色与房间入口沿用常规持久化流程。已有场景文档优先读取。
- 固定地块含中央石板广场、南侧主街、四座建筑和沿边入口。样板新角色的无方向入场优先走南侧，指定来向仍按现有规则。地图继续用同一套移动、门口和战斗规则。
- Pixi 共享图集含建筑、树冠、井、摊位、栅栏和花箱。样板按服务端门和封边定位图片，加载失败沿用已有基础绘画。贴图资源按需加载。独立复验发现水井和摊位原本覆盖可行走格，修正为真实不可通行占地；栅栏旋转到实际封边切向。复验确认两个问题已解决。
- 本地隔离库 `qingyu_white_stone_preview_20261118`，前端 `http://localhost:5173`，后端 `127.0.0.1:15196`。首次通过 `127.0.0.1:15197` 检查时，浏览器 POST 来源与后端配置不符而返回 403；预览已改到后端配置的来源。
- 相关单元测试通过，工程检查覆盖 159 个归属源文件和 88 条路由。真实 Pixi 页面完成两种尺寸的截图并验证了图集 12 个帧。独立视觉审查确认构图地标和旅店位置；远景时建筑被缩小，店铺周围的配套陈设、街边铺装和横屏遮挡仍与参考有差距。场景路径服务返回南门到旅店的 17 格路线，隔离测试观察到角色短途实际推进到门前。
- 使用正确预览地址完成浏览器复跑，确认短途真实移动至旅店门口、点击进入旅店、同画布开战、切换大世界与返回战斗、结束战斗、通过原门返回及重进后四扇门 ID 不变。战斗夹具把第二名临时玩家预置到旅店门前。长路线回放因本机世界调度等待数据库超时，未声明完整走完 17 格。
- 横屏独立复验曾发现入口人物被探索栏遮挡。样板镜头现为下栏预留空间，以直接从 844×390 打开的隔离页面重新抓图，独立复验确认入口角色出现在热栏上方。横屏构图仍偏总览，建筑与门牌比参考更小。未建立有效的前后性能对照，未覆盖手机真机。正式服状态见页首发布补记。
