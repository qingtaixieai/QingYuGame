# 室外二级地图运行阶段（2026-10-24）

状态：2026-10-25完成本阶段实现、本地回归和整阶段代理验收。未部署、未推送。本阶段是室外二级地图运行闭环，不代表完整二级地图内容或所有后续玩法已经完成。

## 已实现范围

- 室外场景首次按需生成并保存，半径15，共721格；已保存地图不随再次进入重生成。一级与二级地形分类独立。当前生成器只有基础地面，尚无完整城镇、室内建筑与资源内容。
- 角色实际进入/离开场景；保存每个场景的位置。有来路时从对应边进入，无来路从合法外圈随机进入；重入优先恢复旧位，受阻时在可达区域寻找最近空位。
- 非战斗逐格移动，前端先预览、再次确认；默认关闭移动，重连清除预览。跨边检查公共通道和对侧入口占位。断线清理移动队列但保留位置。
- 实际场景内原位开战并纳入场景居民；一级地图发起时仅把双方移入内部合法格，同一级格的世界旁观者不自动参战。增援外圈入场、下一轮行动；战后保留位置；撤离进入相邻场景对应边。旧无场景引用的战斗仍用半径6。
- 场景遗留物保留局部坐标，世界层或其他局部格不能隔空拾取。场景位置和战斗位置使用同一套地形及占位校验。

## 数据与接口

- V21：scene_positions、world_arrivals及战斗/遗留物场景引用。
- V22：修正遗留物局部坐标约束，场景清理级联删除所属遗留物。
- GET /api/scene；POST /api/scene/enter、leave、move、cross。细节见前后端接口文档。
- 快照只发送场景ID、位置、居民和遗留物，地图单独按需读取，避免每次广播发送721格。

## 审查发现及处理

- 入场内部方法补上世界版本及地块归属校验；非相邻迁移清除旧来路，防止传送后沿错误方向进入。
- 修复前端移动请求多带地图字段导致严格反序列化拒绝的问题；请求只发送version/q/r。
- 补齐会话失效、广播发现断线、入战及重置世界时的场景路径清理；NPC寻找目标先筛同一实际位置，避免先选中另一层玩家而漏掉合法目标。
- 修复侧栏和上下栏遮挡场景控制条，保留全屏地图布局。
- 代理曾怀疑方向常量不一致、无来路随机入场和战斗切世界空白；补充真实常量、最新设计第75/78条及隐藏入口的CSS后，代理撤回这些阻塞判断，未擅自改动已确认规则。
- 早期代理超时、轮次超限及额度中断均未计作通过；恢复后取得明确结论再关闭本阶段验收。

## 发布与恢复边界

此次只在隔离本地数据库应用V21/V22。正式上线前需备份数据库并核对应用版本；既有场景不重生成。回退涉及持久位置/遗留物坐标，应恢复匹配数据库备份与应用版本，不能仅删除已应用迁移或回滚JAR后宣称兼容。
