# 青屿二级、三级场景与 PixiJS 战场

本地分支 `codex/online-scene-pixi-20261110` 从线上 V19 功能提交 `c23acb3` 建立。部署记录位于 `32fd7a8`。场景持久化、制作服务和室内战斗接口从已提交的 `6cdb578` 选择性移植，原工作区的未提交实验保留在原处。本分支尚未发布。

## 运行路径

- 一级地图点击「进入当前地块 · 二级地图」。到达建筑的门格后，右上角出现通行操作。室内通过门返回室外，二级地图可返回一级。
- 二级和三级共用 `SceneView`。点选六边格后左下角显示详情、路线长度及「前往」。服务器按步推进，前端在收到位置更新时补间显示。地图工具在右侧。
- 战斗仍由后端执行行动合法性、行动点、攻击预设、回合和撤离。PixiJS 画布绘制地形、红格、范围、角色、血量和掉落，顺序条、热栏、战斗记录保留 DOM 控件。战斗中可切到一级地图查看。
- 封边只阻断该边。整格墙体、家具和深水由 `walkable=false` 标记。三级出口位于 `(0,radius-1)`，旧外缘位置不生成格子。每个房间有独立战场。

## 接口和数据

`GET /api/scene` 返回当前活动场景、角色坐标、格子列表与 `blockedEdges`。封边元素包含 `from` 和 `to` 两个轴坐标。通过 `POST /api/scene/enter|leave|move|cross|door` 改变场景状态，命令带当前世界 `version`。移动返回服务器认可的路径。WebSocket 的 `scenePosition`、`sceneMoving`、`sceneResidents`、`sceneDoors`、`sceneObjects` 和 `sceneLoot` 驱动界面。`GET /api/battle/current` 在分层战场中返回相同地形的 `cells`、`blockedEdges` 和 `sceneLevel`。数据从 Flyway V20 至 V24 迁移，生成的场景文档随数据库持久保存。

## 验收

- Maven 回归可用 `PHASE1_DATABASE_URL` 指向专用本机 `qingyu_phase1_*` 数据库。回归会清理该数据库中的测试场景。
- 前端使用 `npm run build`。本机预览使用 Vite 的 `QINGYU_DEV_BACKEND`，将 API 和 WebSocket 转发至本机后端。
- 浏览器验收关注一级进入城镇、点格预览与前往、到门口后通行、内收出口、桌面和横屏操作区域、室内发起战斗及战斗地图查看。
