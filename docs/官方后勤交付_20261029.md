# 官方后勤阶段交付（2026-10-29，本地）

## 实现范围

独立后勤驻点与人员、官方服务名单、实际缺口与全站备货目标、独占认领及版本、物品预留、采购批次和资金来源账。运输者先用现货，可按原批次成本当面调货，同类缺口合并采购，再逐个交付；采购、移动、过门、交接和交尸领奖使用现有世界处理器，不用后台加货或瞬移替代行动。

跨驻点派单要求双方允许且保留最低人员；同站优先，然后按紧急程度、创建时间和稳定编号安排。重启保留实物、需求、批次和已完成数量，运行时重新规划路径。缺口变化使旧报价失效，取消不退货、不退已花成本。

守卫仍持有尸体直到当面交接成功；后勤员实际携带并到执法设施领奖。长阻释放后仍由活后勤员持有的尸体任务会在冷却后归实际持有者继续办理；掉落或转给非后勤人员则取消原交接，保留实物，官方人员重新持有时可重新产生需求。原守卫死亡不撤销已交出的尸体任务。

找不到收货人时到配置驻点等候；未到达、移动或战斗期间不累计提货等待。提货状态下受阻也会累计受阻时间并释放，防止永久占用任务。短暂停留请求允许NPC拒绝，同意5秒、同一请求者冷却10秒，不控制玩家，不强制打断战斗。后勤员战斗中接近收货人及交付仍通过共用step和payHandover扣行动点。

交接与执法界面增加官方后勤只读状态和管理员账目；普通账号只收到自己相关任务，不收到管理员账目或隐藏目标坐标。暂不开放玩家配送订单。V30新增相关表及预留约束。
