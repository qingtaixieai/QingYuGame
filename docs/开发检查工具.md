# 轻量开发检查

运行位置不受限制。下面命令假定已进入仓库根目录；Python 3、Node 22+、Maven和JDK 21+需在环境中配置。检查结果、截图和日志保存在忽略目录 `.local/devcheck/<时间>/`。脚本没有部署能力，也不自动执行会写入游戏数据的历史冒烟脚本。

## 一键本地验收

`python scripts/devcheck.py local`

本机默认Java为17，应使用项目已有JDK：`python scripts/devcheck.py local --java-home D:/IDEA/java`。只影响该次检查，不修改系统环境。

依次运行工具自身测试、前端构建、背包/小船/地图手势纯逻辑测试、Maven verify。某项失败仍汇总其余结果，退出码非零；完整日志单独保存。数据库联测不包含在此入口中，需按项目检查助手建议在隔离环境运行。

## 战斗卡住诊断

通过环境变量 `QA_DATABASE_URL` 指定数据库连接，不把密码写入命令参数或文档。然后运行：

`python scripts/devcheck.py battle`

数据库查询在 `BEGIN READ ONLY` 中运行，有连接/查询超时，只列活动战场的轮次、行动者ID、行动点、截止时间、参战人数及最近事件时间，最多100场。过期超过5秒、行动者不在战场、负行动点会报疑点。间隔几秒再次运行，对比同一战场才可判断是否持续卡住；不自动跳过回合或修复数据。

也可分析已有快照：`python scripts/devcheck.py battle --snapshot .local/devcheck/<时间>/battle.json`。
附加 `--log <后端日志路径>` 只汇总日志尾部1MB的错误关键词数量，不输出原文。需要远端诊断时可在服务器部署同一只读脚本或经已有安全连接导出快照；本工具不新增SSH凭据管理。

## 手机巡检和性能采样

`python scripts/devcheck.py browser --url http://127.0.0.1:5173`

复用本机已安装的Playwright运行时；其他机器可设置 `QA_PLAYWRIGHT_MODULE` 指向其index.mjs，或安装Playwright。默认使用Edge隔离无头浏览器，不读取个人浏览器资料。

可设置 `QA_STORAGE_STATE` 为专用测试账号的Playwright登录状态文件；其中含会话凭据，只保存在 `.local`。或者设置 `QA_HEADED=1` 后，在开始15秒内手动登录/准备场景。登录可能影响该测试账号其他设备会话，应使用专用账号。

保存1280×800和844×390截图、当前页及可见的聊天室/人物侧栏截图，检测横向溢出和疑似被遮挡的控件。遮挡候选需要看截图复核，不直接当失败。未登录会明确报未覆盖游戏，而不会把登录页冒充验收通过。

最后采样10秒requestAnimationFrame间隔及浏览器长任务：P95、最大帧间隔、超过50ms次数。它不自动乘船/开启战斗；测小船需先准备正在航行的场景。结果是桌面模拟，不是手机真机FPS，也无法单靠帧间隔证明网络是根因。

## 部署后只读验收

`python scripts/devcheck.py deploy --url https://qingtaixieai.com --dist frontend/dist`

检查健康接口、页面引用的同域JS/CSS响应与类型，并与指定本地构建逐字节比较，输出SHA256。省略 `--dist` 只检查可用性，不能声称版本匹配。此入口无法证明服务器JAR版本、systemd状态或后端日志正常；仍按现有部署流程检查这些项目。

## 自动化边界

这些是手动或由开发助手按任务调用的入口，不挂到每次Stop执行。原Stop钩子继续只做轻量提醒。所有报告区分失败、缺环境及未覆盖项；不自动提交或推送运行产物。
