## 一级 Pixi 底座统一二三级

用户确认二三级改用一级地图的绘制和操作。SceneView 提供局部场景数据与交互 UI，MapView 统一绘制、手势、镜头控件、路径点与人物位置插值。二三级沿用本地门、跨格、服务、物品及角色位置。点格后由 GET /api/scene/route 取只读路线，按「前往」才调用 POST /api/scene/move，服务器从确认时的实际位置重新计算。设施预览寻找可达相邻格，实际制作仍按原服务规则。取消选格、断线和切图会让旧预览响应失效。

SceneMap 增加可选 blockedEdges。共享边在服务端按坐标归一化，探索和同场战斗都不能穿过。战斗保留既有行动点和选格流程，并显示封边及扣除其后的不可直达格。整格不可走由 cells.walkable 表达，旅馆墙格在 Pixi 中整块绘制。旧场景 JSON 无 blockedEdges 时按空集合读取。TownService 和 SceneContentService 更新地格时保留封边。SceneTopology 复用一级最短路的排序与算法，实际逐步移动检查直接相邻边，不能拿绕路可达当作一步可穿过。战斗继续使用原有等代价搜索顺序，加入封边过滤。

新二级地图用 SceneLandscape 版本 3 按世界种子与一级坐标生成，已保存场景保留原文档。林地、平原、丘陵、水岸、城镇按类型铺成片地形，开放的一级相邻地块用于城镇道路方向。高岩或深水使用整格阻挡，城镇可生成短栅栏封边。生成时从中心验证六个方向；发现断路则撤掉自然阻挡和栅栏再用基础布局。固定种子 240910 已跑五类样本，每个 721 格、六向可达；水岸 31 个封格、丘陵 32 个封格、城镇 3 条封边。样本为内容设施二次布置前的地形输出；实际城镇放置建筑时另做连通校验。
