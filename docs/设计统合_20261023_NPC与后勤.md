## 1. 执法人员、公告栏与奖励
### 1.1 交尸清罪与奖励
- 死亡不清罪，离区恢复仍按既定规则。尸体保留该次死亡时对应势力的有效通缉资格。
- 交尸只清该次死亡之前、接收势力的对应犯罪记录；复活后新增犯罪保留，其他势力记录保留。
- 奖励按死亡时有效通缉确定并随尸体保存；后来记录自然到期、新犯罪或配置变化不改变该尸体已保存奖励。
- 当前每具有效尸体1银币，不按犯罪条数叠加；多个势力可各保存资格，但只能选一方交尸一次。
- 到相应势力任一可办理执法人员处逐具提交；由实际提交者领取实体银币，直接入背包。
- 交尸界面仅列本势力可受理尸体。确认前显示身份、势力、1银币及将清除的死亡前记录。
- 收尸、发钱、清除对应旧记录一次完整结算，失败都不生效；尸体收走，不能重复兑奖。
- 服务人员死亡或其实际场景在战斗中，暂停办理；其他独立场景战斗不影响。可改去同势力其他可办理人员处，但仍实际移动。
- 进入战斗立即关闭交尸确认，未完成不生效，已完整结算不回退。
- 已确认隐藏钱币储备概念，未来不足时不收尸、不清罪、不欠款，等待补充或另处兑换；首期与商店一样无限储备，补充机制以后实现。
- 防刷明确暂缓；一次兑现与事务完整性不是新加领奖冷却。
### 1.2 悬赏公告栏
- 执法所旁有公告栏，只展示本势力通缉信息，不是交尸入口，不提供追踪/定位/寻路。
- 内容：名字、外观、通缉原因、奖励；无实时位置、无最后出现地点。
- 同一对象在该势力合并一条，展开原因，不重复悬赏金额。
- 须在互动距离查看；远处只有对象简介，离开互动距离自动关榜。
- 打开期间同步更新；新通缉加入，记录清除移除，仅死亡而记录未清者仍在榜。
- 不依赖执法人员存活。公告栏是普通信息对象，战斗中可查看更新，不消耗AP；不能把交尸服务停办套到公告栏。

## 2. NPC决策（已确认）
- 结构：硬规则筛选 → 合法候选评分 → 保持当前任务 → 共用动作处理器执行并再次校验。
- 根据距离、危险、状态、职责等评估；具体权重、阈值不定死，不能用高分覆盖强制规则。
- 关键变化触发重新判断，加低频检查；不是每帧全量算。
- 新选择明显更好才切换；当前目标失效立即重评。分数接近优先当前选择，无当前选择则在接近最高分的合法项随机选。
- 按角色类型基础权重，允许个体微调；生成时确定并保存，不加经历成长系统。
- 无合法行动等待重试；战斗中无动作则结束回合。同动作反复失败降频，相关情况变化及时重试。
- 优先按实际可走路线评距离，不用直线格数误选隔墙目标；明确不可达排除，未知不等于不可达。
- 临时人堵路先短等，有合理绕路才绕，持续堵塞重评；不穿人、不擅自攻击挡路者。
- 信息来源仅自身可得信息、最新地点实时位置规则及既定守卫报警；不读取隐藏对象/他人背包。
- 普通NPC丢失目标，赴最后见到位置查看，仍无目标则重评；途中新目标明显更好才切换。后勤找人另有提货流程。
- 失去追击目标后实际返回原活动区/岗位；无法返回附近合法位置等待降频重试，不自动更换活动区。
- 普通游荡NPC就近随机点移动后停留，守卫仍固定岗不巡逻。
- 普通NPC低血量按类型/个体偏好撤离，守卫也可撤但职责权重更高；遵守与玩家相同撤离规则。
- 恢复仅合法药物/旅店等，检查条件，不自动回血。
- 能交易的角色按类型配置主动买补给，按目标数量缺多少买多少，不无限采购。商店缺货或失效则评估其他已知可达合法店，无合适者等待，不读取未知库存。
- 首批NPC无限钱，仍检查商店库存、价格、距离、战斗条件及实际持有物品。
- 守卫离岗补给须满足岗位最低留守，缺人保留需求等待接替；也可由后勤代购配送，两种并存。
- 携尸守卫优先交付再接新派遣，途中正常应战；后勤实际接手后，守卫才结束送尸任务。
- 纯技术实现不得用“权重”擅自改既有先来报警、最低留守等硬规则。

## 3. 地点实时位置信息（最新覆盖）
- 同一地点连续占据的一级地块内，普通角色位置实时可知，玩家/NPC共用信息；不是无限相邻地块递归，也不是固定周围六格。
- 隐身/隐藏例外，不提供其实时位置；只保留带时间标识的最后已知位置，不能冒充当前位置。
- 外部看室内人物只知所在建筑，不知室内具体格；进入同一室内后才知格子位置；不把室内角色画在室外二级场景。
- 对象离开范围，直接获知“丢失目标”，不再把旧位置当当前；此通知不是获知其新的隐藏位置。
- 后勤可进可通行建筑实际找人交付，走门及入战规则正常。
- 位置实时共享不自动共享背包、未发现地形细节、任务、商店库存或悬赏榜远程访问权限。
- 旧总账“仅观察时显示实时状态”须按信息种类理解：本节明确扩大角色位置，设施占用等其他实时状态没有随之全域公开。
- 悬赏榜仍仅信息展示，无位置功能；地点位置获取是独立已确认机制。

## 4. 当面交接、赠送与出售
- 二级及三级角色不得同格；交接须同实际场景相邻一格。
- 一次选好一批，战斗中由交出方在自己的回合执行，成功转移扣其1AP，接收方不扣；接收方确认不要求轮到接收方，且不暂停当前回合。非战斗不扣战斗AP。
- 接收方同意：玩家确认、NPC按需求/任务判断；按实际需求接收部分数量/种类，多余留交出者。
- 交接是当场一次行动，不建立跨回合预约。确认期间只临时锁所选物品，已有制作等锁定物品不能再次选择。
- 回合结束、脱离相邻、切场景、拒绝/取消使未完成交接失效并解锁，不转物不扣AP；不暂停回合等待。
- 实际交出与快跑双向互斥，仅接收不受影响；失败取消不算完成交接。
- 分赠送与出售，后勤配送通常出售；确认前展示实际数量及总价。
- 出售按实际接收数量付款，价格首期沿用对应商店售价，不额外收配送费。
- 资金不足允许选择买得起部分，不欠款、不强扣。首期NPC无限钱例外不推广给玩家。
- 成交时物品、钱、交出AP整体结算，失效全部不扣；数量/价格变化需要以明确的实际报价征得同意，不能静默追加扣款。
- 普通玩家当面赠送/出售保留；玩家配送下单是另一个暂缓系统，不混为一谈。

## 5. 后勤身份、钱币与库存
- 专用配送单位，是临时库存持有人/中间人，不是商店，不新增职业系统（职业以后）。
- 官方固定发工资的制度适用守卫与后勤；首期仅记录，实际工资周期/财政结算以后做，不按配送件数发劳务报酬。
- 后勤先垫采购款，出售收款归还采购资金来源；官方出款归官方，后勤垫款归后勤，与工资和悬赏分开。
- 首批NPC无限钱仍有效，不用它生成无限实物或自动完成采购。
- 后勤实际交尸的1银币奖励归后勤本人，不转回击杀守卫，不算配送费。
- 优先已有库存，不足再采购；可合并采购、分别配送，每个需求独立认领与结算。
- 需求取消后的已购物品保留供以后配送，不自动退款，实际出售才收回垫款。
- 目标不缺药则不交；缺多少交多少，多余留后勤。
- 各驻点配置少量备货目标，按本站后勤携带的可用库存合计，不每个人重复一套。
- 备货需求生成采购任务由一人认领。通常实际配送优先；已在备货途中是否切任务按权重及“明显更好才切”决定。
- 预留给某需求的物品不得重复承诺，必须解除/调整原分配才改用；可用库存不包含已分配部分。
- 药品不自动替代，指定品种缺货就等待/另找合法已知商店。
- 后勤间可实际当面调货，遵守共享交接；按原采购成本结清垫款，接手者承担库存并收回后续货款。
- 紧缺库存优先紧急需求，同紧急按需求先后；缺口继续找店/等待。
- 路线考虑已知危险，可稍绕，不读取未知敌情、不强制地图生绕路。
- 认领派遣评估实际路程与现有任务，不仅“谁先看见”。

## 6. 后勤任务生命周期
- 首期只服务配置允许的官方人员，不实现玩家配送。不是全势力所有目标自动可服务。
- 负责采购配送、接手通缉尸体交执法人员。尸体取空才能入包、背包暂停计时等规则共用。
- 后勤到达后与守卫当面交接；交接前守卫继续自行送，不原地无限等。交接成功才解除守卫携尸任务。
- 紧急补给优先，同等紧急按实际路程，已携尸体不因改任务自动丢下；任务切换仍受稳定规则约束。
- 需求同时只有一位认领者；死亡或不能继续则释放未交付部分，不释放已完成部分。
- 遇袭按生存偏好反击/撤离，安全后继续；能主动进战场送货，按正常加入与下一轮行动规则，不免伤不跳回合。
- 战斗阻碍短时保留任务，长期无法执行才释放，时长待测试。物品不因释放而远程转走。
- 被其他后勤接手后原执行者不再送旧单，须新认领或普通当面交易，不双重完成。
- 收货者死亡取消未交付部分；复活/补岗人员按实际缺口重新提出需求，不继承死亡对象旧单。
- 同对象同物品新需求更新原剩余数量，不重复多单，已完成不回退。
- 抵达却暂不能交接可短等，持续无法完成释放未交付部分。
- 后勤无任务实际返驻点，库存随身，途中可响应新任务。
- 驻点与守卫岗分开配置，可执法所附近或室内/室外，数量按驻点不套城市档。
- 本地服务优先，跨地点支援配置允许；外派须保本站最低人数。本地新紧急需求先留守人员处理，不直接召回已外派配送者。

## 7. 找人、停下请求与提货
- 后勤按当前合法已知位置接近，附近发送停下请求；不强制角色定身。
- 玩家若参与普通交接自主同意，NPC按任务决定；官方配送首期不因此开放玩家订单。
- 同意后取消剩余路径，交接后重新选行动。拒绝/无响应不连续催促，等待后重评。
- 等候者可随时离开；后勤重评，不强迫取消整项配送才能移动。战斗计时不停。
- 后勤丢失/找不到目标，指定提货点并通过该官方配送任务通知地点/期限；不暴露后勤实时位置等额外信息。
- 本地使用驻点，外派用服务地预配置提货点，可室内/室外。
- 到点才开始等待计时，路程不算逾期；可在附近处理不妨碍交付事务，遇袭正常应战。
- 超时未交付释放未完成需求，物品留后勤；多需求各自计时，不互相拖住。
- 提货点进入战斗暂停提货超时（不是暂停回合），仍可按战斗交接规则交货。
- 后勤被迫离开则通知暂无法提货并暂停等待计时，恢复可交付后继续；不远程交物。
- 已失去认领权的旧执行者不能凭旧单完成配送。

## 8. 已解决、替换与暂缓
已解决：
- 旧尸体清除范围：只清死亡前对应势力，新犯罪保留。
- 奖励：目前1银币，死亡时确定，实际交尸者领取，逐具一次结算。
- NPC决策：硬筛选+评分+任务保持，不引入多套动作执行。
- 后勤：专用中间人非商店；工资非按件；资金首期无限但物品真实。

替换：
- “死亡清罪/整势力全部当前记录清除” → 交尸清死亡前记录。
- “后勤移动商店/配送劳务按量计酬” → 中间人，货款按实交量，官方固定工资以后落地。
- “所有NPC没有资源差异” → 首期无限钱是明确例外，其他共用校验不变。
- “仅直接视野内角色位置实时” → 同地点连续一级范围实时，隐藏除外、室内只建筑。
- “玩家可下配送单”及其自动补给/修改取消/提货界面 → 整体重思暂缓。

暂缓：玩家配送、职业、实际工资、有限财政与执法储备补充、高犯罪度野外追捕、防刷奖励；不得以技术补完之名加入。

## 9. 开工前检查与建议（不是新增确认）
### 9.1 技术保障建议
- 需求ID与认领版本、交接事务ID、尸体唯一身份、犯罪事件时间/版本边界需要一致性保障，防重复执行与过期认领完成。不等于用户暂缓的刷奖励限制。
- NPC无限钱不应编码成可向玩家转出的无限堆叠钱币；具体资源表示须核对交易实现，不能绕过物品/价款结算。
- 服务器重启持久化至少覆盖尸体暂停剩余时间/奖励资格、犯罪事件、已完成结算；避免重启复活尸体重复领取。任务重启恢复策略要明确，不能静默瞬移送货。
- 官方需求通知仅用于任务协同，不让NPC额外窥视隐藏位置。
- 旧尸体在旧犯罪自然恢复后仍有既定奖励资格，但不得删除后来新犯罪；须用死亡时记录快照/边界定位，不能按名字一键清所有。
- 处于实际战斗的所有角色仍受统一规则，即使AI任务标记等待也不能跳过回合/伤害。
### 9.2 真正需补充或核对的少量边界
1. 已确认A：进入提货等待后只使用提货等待计时；战斗暂停此计时，不再被配送长期受阻计时提前释放。死亡、需求取消等仍正常终止任务。
2. 已确认A：官方NPC生成时预知所属服务地点的公共商店、执法所、驻点与提货点；不因此知道隐藏对象、商店实时库存或全世界地图。
3. 已确认A：首期不增加隐身/隐藏收货者主动共享位置功能；恢复可获取位置后配送，或自行到提货点。
4. 普通角色在不同场景但同一地点的实时位置与战斗合法目标必须分开；知道所在位置不意味着可跨场景攻击/交接。属于已有规则的实现核对，不必重新投票。
5. 交接1AP、出售含多种物品的价格、双方确认时数量变化需统一报价校验；玩家配送暂缓不影响普通玩家交易。
