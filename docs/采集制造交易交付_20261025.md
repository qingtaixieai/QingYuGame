# 采集、制造与交易阶段（2026-10-25）

基线 `bcc18c0`，分支 `codex/persistent-scenes-20261023`。本阶段仅本地开发和隔离数据库验证；没有部署或推送。此文优先于历史文档中“采集制造尚未开工”的状态描述，不覆盖未实现的设计。

## 已实现范围

- 二级室外地图持久资源对象：树木、铁矿脉、纤维植物、小石头；一级地图只显示概况并引导进入。采集要求同格，树木需手持斧类，铁矿需手持镐类。普通采集必成功；石头即时拾取，其他资源分别耗时5/8/3秒。
- 资源按绝对时间恢复：树木120秒、铁矿180秒、纤维60秒；石头30秒后在对应平原场景的可走草地/土格随机出现。无人不暂停时间。界面显示耗尽/树桩，不显示恢复倒计时。
- 城镇/村庄室外工作区域生成工作台、熔炉、铁砧，占用不可走格；相邻使用，容量分别2/2/1。公开信息仅空闲/有人使用，不暴露他人的任务、倒计时。
- 配方：铁锭、普通箭矢、绷带、斧头、镐子、剥皮刀、长枪、轻甲。普通箭矢一批3秒产10支。材料/消耗品支持1/5/10批，装备1批。
- 材料整批预留，逐批消费和产出；取消保留完成产物，释放未用材料。背包展示总量、可用量和预留量；装备、消耗、交易、丢弃、造船材料不能越过预留保护，数据库扣减触发器兜底。
- 持续任务单槽，与旧休整互斥。便携制作可在同一实际场景移动；设施制作/采集移动中断。切场景、进入战斗、最后连接断开和服务启动取消未完成任务，不离线生产。NPC共用处理器，仅在线连接要求有角色控制器差异。
- 镐子可双手装备，基础伤害3、AP2、相邻单格，武器攻击忽略本次1点护甲，不穿盾。剥皮刀为匕首类、单手伤害2、AP2。
- 首批指定毛皮兽映射为现有利爪怪；尸体同格或本人携带且手持匕首可剥皮，8秒，80%成功得兽皮1。成功/失败均消耗尸体，中断不消耗。地面尸体内部物品转为同位置小袋。
- 尸体必须取空后携带；携带暂停剩余消失时间，放下恢复剩余时间。已开始剥皮可持有到期尸体至结算；取消时到期尸体清理。玩家保留尸体类型扩展，但死亡不生成尸体或自动掉落。
- 商店请求必须有requestId；同人同ID同载荷返回持久成功结果，不二次扣款/给货；改载荷拒绝。失败事务回滚且不缓存成功。浏览器保存待确认ID以便重试。

## 明确未实现及边界

- 完整城镇室内、进店门禁、正式服务NPC、收费旅店与官方后勤不在本阶段。商店仍沿用已有一级城镇入口；旧休整只补单槽互斥，不声称实现5铜收费旅店。
- 不增加耐久、燃料、熟练度、天赋、负重、玩家建造或新技能。
- 新镐/剥皮刀临时沿用斧头的100铜买价/20铜卖价，仅实现基准，经济平衡未作新的用户确认。
- 首批剥皮产物/概率固定为兽皮1/80%；数据库预留物种采集表，尚未实现多物种多掉落配置器。
- 设施目前为基础地图标记，并非完整建筑美术。所有新增动作可供NPC调用，但没有新增自主采集/制造AI策略。
